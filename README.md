# AI创作资产库 · Vault Studio

> 面向 AI 创作者的本地素材与提示词管理工具，Windows 桌面软件（Electron 封装）。

所有数据保存在**本机**（IndexedDB），**不上云**，不用担心隐私和平台跑路。适合长期积累创作资产：提示词、参考图、人物设定、场景、色板、成片……越用越值钱。

## 📥 下载与安装

直接下载安装包即可（**无需安装 Node.js、无需任何技术基础**）：

- 下载页：<https://github.com/RICE416529/vault-studio/releases>

## 🧭 使用指南

### 1. 收藏库（📥）
随手保存平时的灵感：
- 上传 / 粘贴文本、图片、视频
- 每条收藏可**拆解**成结构化区块（起手式、人设、场景……），方便在拼装台二次使用

### 2. 拼装台（🛠）
把提示词按模块「搭积木」：
1. 点选分类区块（起手式 / 风格 / 人设 / 场景 / 内容主体 / 构图与镜头 / 正面 / 负面 / 视频动态 / 组合）往草稿里加内容
2. 顶部「🌐 翻译台」支持中英互译
3. 拼装完成：导出成品，或「💾 存到提示词库」留档

### 3. 图库（🖼）
集中浏览与管理参考图，可作为素材中转站。

### 4. 资产库（🎬）— 核心模块
以「集」为单位沉淀可复用的资产：
- **建集**：人物、场景、色板、提示词、成片……分类可自定义（右上 🗂 分类按钮）
- **集内挂子资产**：三视图、配饰、多角度、局部细节……
- **项目 / 影片**：如「悬疑短片·旧公寓」，把相关人物/场景归到同一个项目下，按项目筛选
- **快捷输入**：名称 / 用途 / 工具 / 调用标注 / 子类型 / 标签 全部带候选 chip——点选填入、✕ 删除、回车新增，少打字
- **提示词资产**：保存时自动中英互译，双语双行显示
- **图片**：上传 / 网址 / **直接 Ctrl+V 粘贴**，支持多张（四视图 / 宫格 / 多角度）
- **成片**：上传视频 / 粘贴网址 / Ctrl+V，可填镜号（自动转拼音首字母）、简介，导出 Briefing

### 5. 导出整理（📦）
把零散素材整理成可直接交付的目录：
1. **导入素材**：从「成片库」下拉选择，或直接把文件拖进面板
2. 自动按 **视频 / 音频 / 图片** 分组，同组内卡片**拖拽排序**
3. 勾选「启用重命名」：前缀 + 序号（位宽可调）+ 后缀，卡片实时预览「→ 新名」
4. 选目标文件夹 → **一键复制导出**，自动生成 `视频/ 音频/ 图片/` 三个子目录，同名自动 `_2/_3` 避让

> 导入、导出全程**只复制、从不移动/删除源文件**，清空清单也只移走列表、不动原始文件，放心用。

### 6. 数据（💾）
- **📦 完整备份**：全库导出成一个 JSON 文件（图片/视频内嵌其中），可存 U 盘 / 网盘
- **📥 导入合并**：按 id **并集去重**——家里 `{A,B}` ∪ 公司 `{C}` = `{A,B,C}`，已存在的不覆盖
- **多机同步**：U 盘 + 备份/导入即可（推荐：公司导出一份 → 回家导入一次）
- 提示词资产导入时自动去重合并，不产生重复

### 7. 皮肤（🎨）
- 默认使用 **明亮科技玻璃**（浅色玻璃质感，第一观感清爽）
- 可选：专业剪辑黑 / 玻璃拟态 / 玻璃霓虹 / 自然玻璃（风景底图，可换成自己的图片）
- 每套风格有专属配色家族（冰蓝、薄荷、丁香……），选择自动保存、刷新不变

## 💾 数据存储位置

数据存在 Electron 用户目录的 IndexedDB 中（与仓库/安装目录无关）：

```
C:\Users\<你的用户名>\AppData\Roaming\prompt-vault-studio\
```

- 换电脑 / 重装系统：先「📦 完整备份」导出，装好后「📥 导入合并」即可恢复
- ⚠️ **卸载软件前务必先备份**——卸载不会自动保留数据

## 🧩 开发与打包（面向开发者）

### 目录结构
| 文件 | 说明 |
|---|---|
| `main.js` | Electron 主进程（本地静态服务器（端口 18745）+ 文件管理 IPC） |
| `index.html` | 前端主程序（单文件，含全部 UI 与逻辑） |
| `pinyin-pro.esm.js` | 拼音库（镜号转首字母） |
| `version.txt` | 版本号（须与 index.html 内 `PAGE_VER` / `APP_VER` 三处一致） |
| `package.json` | 依赖与打包配置 |
| `resources/` | 图标、ffmpeg 等资源 |
| `build.cjs` | 打包脚本（Electron 内置 Node 程序化调用 electron-builder） |

### 开发模式运行
```bash
npm install
npm start            # 或：node_modules\electron\dist\electron.exe .
```

### 打包成安装包
```bash
npm run dist         # 在 Windows 上执行，输出 dist\AI创作资产库 Setup x.x.x.exe
```
> 国内网络下打包需先配置 electron-builder 二进制镜像（build.cjs 内已写好，直接跑即可）。

## ❓ 常见问题

- **安装后打不开 / 闪退**：先确认安装完整；右键快捷方式「以管理员身份运行」试一次；仍有问题请到 Releases 页面留言反馈。
- **数据怎么搬到另一台电脑**：U 盘 + 「完整备份 / 导入合并」，见上文第 6 节。
- **之前发的下载链接还有效吗**：有效。安装包更新时保持同一个下载地址，**重新下载即为最新版**（无需换链接）。
- **网页版还维护吗**：已弃用，专注桌面版。
- **会不会偷偷上传我的数据**：不会。纯本地存储，无任何网络上报；「自动更新检查」仅对比版本号，桌面端默认关闭。
